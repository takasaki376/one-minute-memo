## タイトル

サインアップAPI実装（POST /api/auth/signup）

## 種別

Task

## 背景

- 認証基盤実装後、ユーザー登録処理をサーバーに移行する。

## 目的

- クライアント直接呼び出しを廃止し、サインアップをAPI Route経由に統一する。

## スコープ

- POST /api/auth/signup 実装
- 入力検証（email/password）
- ユーザー作成
- 失敗時エラー返却

## 対応内容

1. API Route実装（POST /api/auth/signup）
2. バリデーション（メール形式/パスワード長）
3. Firebase側ユーザー作成
4. 成功時に統一レスポンス返却
5. 失敗時に code/message 形式で返却

## 完了条件（Acceptance Criteria）

- API経由でサインアップ可能
- 重複メール等のエラーが適切に返る
- 既存UIから呼び出し可能な契約を満たす

## 想定リスク

- エラー分類漏れ
- 既存UIとの契約差異

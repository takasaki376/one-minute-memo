# PWA対応（ホーム画面追加・オフライン対応）

## 概要

1分メモアプリをPWA（Progressive Web App）に対応し、スマートフォンやPCでネイティブアプリのように利用できるようにする。

ホーム画面への追加、アプリアイコン、スプラッシュ画面、オフライン利用をサポートする。

---

## 背景

現在は通常のWebアプリとして利用しているため、毎回ブラウザからアクセスする必要がある。

PWA対応することで、以下のメリットが得られる。

- ホーム画面からワンタップで起動できる
- ブラウザのUIを表示しないアプリライクな画面で利用できる
- IndexedDBを利用したオフライン利用が可能となる
- キャッシュにより起動速度を向上できる

---

## 対応内容

### 1. Web App Manifestの追加

以下の設定を追加する。

- アプリ名
- 短縮名
- start_url
- display（standalone）
- テーマカラー
- 背景色
- アイコン

### 2. アプリアイコン追加

以下のアイコンを作成・設定する。

- 192×192
- 512×512
- Maskable Icon

### 3. Service Worker導入

Service Workerを導入し、静的リソースをキャッシュする。

対象例

- HTML
- JavaScript
- CSS
- フォント
- 画像

初回アクセス後はオフラインでも起動可能とする。

### 4. オフライン対応

IndexedDBに保存されているデータを利用し、通信がない状態でも以下の機能を利用できること。

- メモ作成
- メモ閲覧
- テーマ管理
- 履歴表示
- 設定画面

### 5. インストール対応

PWAのインストール要件を満たし、各OSでホーム画面またはアプリとして追加できるようにする。

- Android
- iPhone（Safari）
- Windows
- macOS

### 6. 更新対応

新しいバージョン公開時にService Workerを更新し、必要に応じて最新バージョンへ切り替えられるようにする。

---

## 受入条件

- Web App Manifestが正常に読み込まれること
- アプリをホーム画面へ追加できること
- standaloneモードで起動できること
- オフライン状態でも起動できること
- オフラインでメモ作成・編集・閲覧ができること
- オフラインでテーマ管理ができること
- IndexedDBへ正常に保存されること
- オンライン復帰後もデータが保持されていること
- LighthouseのPWA要件を満たすこと
- Android・iPhone・Windows・macOSでインストールできること

---

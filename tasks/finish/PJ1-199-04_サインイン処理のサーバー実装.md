## タイトル

サインインAPI実装（POST /api/auth/signin）

## 種別

Task

## 背景

- ログイン処理をクライアントからサーバーへ移し、セッションをhttpOnly Cookieで管理したい。

## 目的

- サインイン成功時にセッションCookieを発行し、サーバー主導認証へ移行する。

## スコープ

- POST /api/auth/signin 実装
- 認証処理
- セッションCookie発行
- エラー応答

## 対応内容

1. API Route実装（POST /api/auth/signin）
2. 入力検証
3. 認証成功時にユーザー情報返却 + Cookie発行
4. 認証失敗時の統一エラー返却

## 完了条件（Acceptance Criteria）

- API経由でログインできる
- ログイン後、Cookieが設定される
- 認証失敗時のエラー形式が統一される

## 想定リスク

- Cookie設定不備
- 認証方式差分による想定外エラー

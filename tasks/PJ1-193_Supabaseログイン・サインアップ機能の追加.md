# Firebaseログイン・サインアップ機能の追加

## 概要

1分メモアプリに、Firebase Authenticationを利用したログイン・サインアップ機能を追加する。

ログイン・サインアップは任意とし、未ログインでもこれまで通りメモアプリを利用できる状態を維持する。
ログインした場合のみ、今後追加予定のクラウドバックアップ機能を利用できる前提とする。

本チケットでは、ユーザーがFirebase Authenticationでアカウント作成・ログイン・ログアウトできる状態までを対象とする。
メモデータのクラウド保存、同期、バックアップ処理は別チケットで対応する。

## 背景

現在、1分メモアプリのデータはブラウザのIndexedDBに保存されている。
今後、Firebase Firestoreを利用したクラウド同期機能を追加するため、まずユーザー認証の仕組みを導入する必要がある。

ただし、ログインを必須にはしない。
既存ユーザーがログインなしで今まで通り使えることを前提とする。

## 対応範囲

- Firebaseプロジェクトへの接続設定
- Firebase Authenticationを利用した任意ログイン機能の実装
- Firebase Authenticationを利用した任意サインアップ機能の実装
- ログアウト機能の実装
- ログイン状態の保持
- ログイン済みユーザー情報の取得
- 未ログイン時とログイン済み時のUI切り替え
- 未ログインでも既存のメモ機能を利用できる状態の維持

## 対応しない範囲

- IndexedDBのメモデータをFirestoreへ保存する処理
- メモデータのバックアップ処理
- メモデータの復元処理
- 複数端末間の同期処理
- ユーザーごとのバックアップ一覧取得処理
- Firebase Storage Security Rulesの実装
- IndexedDBの既存データ構造変更
- ログイン必須化
- サインアップ必須化

## 想定仕様

### 認証方式

まずは以下のいずれか、または両方に対応する。

- メールアドレス + パスワードによるサインアップ・ログイン
- メールリンク認証

最初の実装では、Firebase Authenticationの標準機能を利用し、独自の認証基盤は作らない。

### サインアップ

- ユーザーは任意でアカウントを作成できる
- サインアップにはメールアドレスを利用する
- パスワード認証を使う場合は、パスワード入力欄を用意する
- 確認メールを送信する
- サインアップ完了後の挙動はFirebase Authenticationの設定に従う
  - メール確認を促すメッセージを表示する

### ログインの扱い

- ログインは任意とする
- 未ログインでも、メモの作成・編集・削除・閲覧はこれまで通り利用できる
- ログイン済みの場合のみ、今後追加予定のクラウドバックアップ機能を利用できる状態にする
- 本チケットではバックアップ機能そのものは実装しない

### 画面・UI

- 未ログイン時も通常のメモ画面を表示する
- 未ログイン時はログイン・サインアップ導線を表示する
- ログイン画面または認証モーダルで、ログインとサインアップを切り替えられる
- ログイン済みの場合はユーザー情報を表示する
- ログイン済みユーザーのメールアドレスを確認できる
- ログイン済みの場合はログアウトボタンを表示する
- バックアップ機能は本チケットでは表示しない、または「ログイン後に利用可能」などの導線に留める

### セッション管理

- ページを再読み込みしてもログイン状態が維持される
- Firebase Authenticationの認証状態を利用してログイン状態を判定する
- ログアウト後は未ログイン状態に戻る
- ログアウト後もローカルのメモデータは削除しない

## 環境変数

以下の環境変数を利用する。

```env
FIREBASE_API_KEY=
FIREBASE_AUTH_DOMAIN=
FIREBASE_PROJECT_ID=
FIREBASE_STORAGE_BUCKET=
FIREBASE_MESSAGING_SENDER_ID=
FIREBASE_APP_ID=
```

フロントエンドフレームワークの仕様に応じて、必要であればプレフィックスを付ける。

例：

```env
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=
```

## 実装メモ

- Firebase Authenticationを利用する
- 認証状態は onAuthStateChanged を利用して管理する
- サインアップは createUserWithEmailAndPassword を利用する
- ログインは signInWithEmailAndPassword を利用する
- メールリンク認証を採用する場合は sendSignInLinkToEmail を利用する
- ログアウトは signOut を利用する
- Firebase Authenticationの永続化機能を利用し、ページリロード後もログイン状態を維持する
- 既存のIndexedDB保存処理には手を入れない
- 未ログイン状態をエラー扱いにしない
- アプリ起動時に未ログインでも通常画面を表示できるようにする
- 今後のFirestore同期機能で利用できるよう、ログイン済みユーザーのUIDを取得できる状態にしておく
- クラウドバックアップ機能は本チケットでは実装しない

## 備考

このチケットではログイン・サインアップ機能のみを追加する。
メモデータをFirestoreへ同期・保存する処理は、後続チケットで対応する。

ログイン・サインアップはバックアップ機能を利用するための任意機能として扱い、アプリ利用の必須条件にはしない。

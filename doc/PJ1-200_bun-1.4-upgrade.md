# PJ1-200: Bun 1.4 アップグレードメモ

## 採用バージョン

| 項目 | 版 |
| --- | --- |
| Bun | `1.4.0` |
| @types/bun | `^1.4.0` |

`mise.toml` と `package.json` の `packageManager` で一致させる。

## 背景

Bun 1.4 は Rust 移植初版。Node.js 互換性向上（Vitest / Playwright 等）、アイドル時 CPU・メモリ削減、Next.js App Router SSR のメモリリーク修正などが含まれる。PJ1-199 認証 API 実装の前にランタイムを揃える。

## 変更範囲

- `mise.toml` / `package.json`（`packageManager`, `@types/bun`）
- `doc/PJ1-197_bun-mise-migration.md` の版数更新

`bun.lock` は依存追加がないため原則そのまま。再生成する場合は PJ1-197 の注意（`node_modules/.bin` 不整合）に従う。

## 検証コマンド

```bash
mise install
bun --version   # 1.4.0
bun install
bun run typecheck
bun run test
bun run build
```

## 既知の注意点

- メジャー相当のアップのため、不具合時は `1.3.14` へロールバック可能
- `@types/bun@1.4.0` はリリース直後に npm 反映が遅れた事例あり（現行は公開済み）
